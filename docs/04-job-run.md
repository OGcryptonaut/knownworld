# Step 4 · The job run

One click. The app:
1. Dedupes your network into unique companies.
2. For each company, checks public job feeds (Greenhouse, Lever, Ashby,
   Workable, SmartRecruiters — the same endpoints their own careers pages
   use), with a web-search fallback for companies not on a known ATS.
3. Streams matches onto the dashboard: role · company · **everyone you know
   there, ranked by closeness** · a drafted warm message per contact.
4. You copy the message into Telegram yourself. The app never sends anything.

Promote any match to the pipeline and track it:
lead → outreach → referred → interview → offer / closed,
with follow-up dates and overdue flags so no thread goes cold.
